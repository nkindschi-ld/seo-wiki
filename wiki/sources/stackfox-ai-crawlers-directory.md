# AI Crawlers & Bots Directory — StackFox

**Citation:** StackFox. "AI Crawlers & Bots Directory."
https://stackfox.co/bots

This is a **living directory**, not a dated article — no publish date
applies; treat contents as current-as-of-retrieval (2026-07-23) and
expect the org/bot list to keep changing.

## Key takeaways

- Tracks AI bots/crawlers across a much wider set of organizations than
  the wiki currently documents: beyond OpenAI/Google/Anthropic/
  Microsoft/Perplexity (already in [[robots-txt-strategy]]), it also
  covers **Meta (4 bots), Amazon (5), xAI (3), ByteDance (3), Cohere
  (2), Mistral AI (1), DeepSeek (1), Allen Institute for AI (3), Zhipu
  AI (1), Apple (3), You.com (1), Brave (1)** — plus infrastructure/
  archive services (Cloudflare, Common Crawl, Internet Archive, LAION,
  Yandex, Huawei, Webz.io, Diffbot, Atlassian, SoftBank) and a 29-bot
  "Other" category. ~94+ documented AI crawlers total.
- Offers per-bot robots.txt-compliance status and site tools (a
  robots.txt generator, a policy-comparison feature) — useful
  operationally, but **individual bot names/purposes were not
  recoverable** via automated fetch (they sit behind expandable
  accordion UI); only organization-level counts were captured.

## What this updates in the wiki

Treat as a **reference pointer**, not a citable finding — no specific
new bot names or claims to add to [[robots-txt-strategy]]'s bot-name
table without independently verifying them (this wiki's practice is not
to fabricate user-agent strings).

- Flags a real coverage gap in [[robots-txt-strategy]]: the wiki's bot
  table only covers ChatGPT/Copilot/Gemini/Claude/Perplexity/Andi/Exa/
  Phind/You.com/Firecrawl/Common Crawl. Meta, Amazon, xAI, ByteDance,
  Cohere, Mistral AI, DeepSeek, and others are undocumented here.
  Added a pointer to this directory as a living reference for anyone
  auditing robots.txt against the fuller/current bot landscape — expand
  with verified vendor-documented user agents in a future ingest rather
  than guessing them from this source.
- No conflicts with existing claims.
