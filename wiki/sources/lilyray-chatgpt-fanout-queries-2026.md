# ChatGPT Fan-Out Queries: Key Findings and Analysis (Lily Ray)

**Citation:** Ray, Lily. "What we can learn from evolving ChatGPT fan-out
queries." Lily Ray SEO Substack. Published 2026-08-17.
https://lilyraynyc.substack.com/p/what-we-can-learn-from-evolving-chatgpt

**Methodology note (rigor caveat):** this is a secondary aggregation —
Lily Ray (a well-known, credible SEO practitioner) synthesizes claims
from ~7 *other* independent researchers/tools (David Konitzny/Peec AI,
Chris Long/Nectiv/Conductor, Suganthan Mohanadasan, Malte Landwehr, Dan
Petrovic, Netcraft), each using different, mostly undisclosed sample
sizes and collection methods (tracked prompts, browser plugins, OpenAI
API extraction, network traffic analysis). No single figure here has a
disclosed, reproducible methodology in the source itself. Treat
individual numbers as directional signals from credible-but-unverified
practitioners, not as a single rigorous study — same treatment given to
other secondhand-aggregation sources in this wiki.

## Key takeaways

- **ChatGPT's fan-out behavior changed sharply with a model update
  ("ChatGPT 5.6")**: single-fan-out-query share dropped from 94.0% to
  43.5%, average retrieved sources roughly doubled (~12 → ~24 pages),
  and (per Chris Long) average fan-out queries per prompt jumped from
  2.17 to 7.61 — a large jump in the same direction as, but far beyond,
  the pre-update ChatGPT rate (2.1/query) already on record in
  [[peec-ai-chatgpt-query-fanouts-2026]].
- **`site:` operator usage in fan-outs jumped from 0.3% to 23%** (Peec
  AI) — ChatGPT increasingly restricts retrieval to specific trusted
  domains rather than open web search, mirroring the site-targeting
  behavior [[peec-ai-chatgpt-query-fanouts-2026]] previously documented
  as a Grok-specific pattern (18.3% of chats) — this suggests
  site-operator targeting is spreading from Grok's aggressive approach
  toward ChatGPT's default behavior.
- **Domain-specific `site:` targeting is query-type-dependent**:
  opinions/reviews → Reddit and specific subreddits; legal/health (YMYL)
  → `.gov` domains exclusively in some tests; product specs/pricing →
  brand official domains (e.g. `site:sephora.com`, `site:costco.com`).
- **Retrieval and citation are diverging**: despite retrieval volume
  roughly doubling, unique domains cited per response *dropped* (19 →
  15) — more pages fetched, but citations concentrating on fewer
  domains, not more.
- **"Decides before it searches" — quantified**: brands named in
  ChatGPT's *initial* fan-out query (before retrieval) get cited 68.9%
  of the time, vs. only 2.1% for brands whose pages were merely fetched
  without being named in the query itself (Suganthan Mohanadasan).
  Separately, initial queries contained brand names the user never
  mentioned in 21 of 27 product-category tests. This is a new,
  precisely-quantified data point for the same mechanism
  [[geosurge-model-memory-predicts-search-2026]] found at the
  category level (training-memory brand recall predicting live-search
  targeting) — here shown to gate *citation* outcome specifically, not
  just search frequency.
- **Product pages now comprise 16.39% of retrieved pages**, while
  listicles, how-to guides, and comparison pages are losing retrieval
  share — a possible early counter-signal to this wiki's long-standing
  listicle-dominance finding, though not framed as a citation-rate
  comparison and not corroborated elsewhere yet.
- **Domain-confusion risk**: ChatGPT has constructed `site:` queries
  against the *wrong* domain — e.g. `site:census.com` for the startup
  Census, which actually operates at `getcensus.com` (Malte Landwehr).
  As `site:`-restricted retrieval grows (per the 0.3%→23% finding
  above), a brand whose official domain the model has wrong becomes
  invisible to that entire retrieval path, not just mis-cited.
- **Security/phishing risk adjacent to the same mechanism**: Netcraft
  found ~1/3 of brand login links generated by LLMs pointed to domains
  the brand didn't own, and ~29% targeted unregistered/parked domains —
  a related but distinct failure mode (generating a wrong URL in an
  *answer*, not just misdirecting a `site:` search).
- **Reddit's retrieve-heavy/cite-rarely pattern gets a sharper number**:
  Dan Petrovic reports ChatGPT discards Reddit retrievals ~99% of the
  time — directionally consistent with, and an even starker figure than,
  [[ahrefs-why-chatgpt-cites-pages-2026]]'s existing 1.93% Reddit
  citation-rate / 67.8%-of-non-cited-URLs-are-Reddit finding. Not logged
  as a conflict — same direction, different precision, undisclosed
  sample behind the newer number.
- **SEO recommendations** (largely consistent with existing wiki
  guidance, plus two new items): build brand recognition so ChatGPT
  considers the brand before searching; keep pricing/specs in crawlable
  HTML (not JS/images); avoid targeting individual fan-out queries
  (spam-penalty risk, unverified mechanism); monitor `site:` search
  impressions in Google Search Console and Bing Webmaster Tools (**new**
  — a concrete, actionable measurement tactic not previously in the
  wiki); and clarify official-domain status via title tag/meta
  description language (**new** — a direct countermeasure to the
  domain-confusion risk above).
