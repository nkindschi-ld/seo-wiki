# DerivateX — "Competitor Citation Steal" Framework (Sharma, 2026)

**Citation:** Apoorv Sharma, "Competitor Citation Steal Prompt," DerivateX, April 10,
2026. https://derivatex.agency/frameworks/competitor-citation-steal-prompt/

An **original tactical framework + executable LLM prompt** (not a research study) for
diagnosing *why* AI engines cite a competitor and not you — at the artifact level —
and systematically displacing them. Tactical companion to the same author's
disclosed-methodology benchmark [[derivatex-two-googles-one-query-aio-vs-serp-2026]].
Written up as the wiki playbook [[competitor-citation-displacement]].

## Key takeaways

- **Gap vs. root cause.** Standard tools show the *citation gap* ("they're cited, I'm
  not"); this targets the *root cause* ("they own a benchmark / definition / Reddit
  presence I lack").
- **Seven-step method:** Citation Mapping → Gap Autopsy → Steal Matrix (rank by
  citation value ÷ steal difficulty) → Artifact Blueprints → Entity Line
  Standardization → 30-Day Steal Calendar → Weekly Diagnostic. Delivered as one
  copy-paste "LLM Citation Intelligence Analyst" prompt that forces artifact-level
  specificity in a fixed-column table (not reproduced verbatim here — proprietary).
- **Premise:** Google rank and AI citation run on different signals — you can rank #1
  on Google and be absent from every AI recommendation in your category (the same
  finding measured in [[derivatex-two-googles-one-query-aio-vs-serp-2026]]).

## Evidence quality

- **The method is original vendor guidance**, sound because it operationalizes
  tactics the wiki independently validates (extractable artifacts/benchmarks,
  first-30% placement, Reddit/community seeding, entity consistency, listicles) — not
  because the framework itself was tested.
- **Cited evidence mostly corroborates existing wiki sources:** AirOps 100-retrieved/
  15-cited ([[airops-fan-out-effect-2026]]), SE Land first-third-2x (wiki's stronger
  figure: 44.2% from first 30%), SE Ranking Reddit/Quora ~4x
  ([[otterly-reddit-geo-ai-search-citations-2026]], 9x), Wix listicles
  ([[wix-generative-engine-optimization]]).
- **One new-but-secondhand data point:** Stacker's "multi-publication distribution →
  up to 325% more AI citations" (late 2025) — logged as unverified pending a primary
  source.
- **Case studies are vendor claims, no disclosed methodology:** REsimpli (zero →
  top-cited across 10+ prompts in 90 days), Gumlet (20% of inbound revenue from
  ChatGPT/Perplexity discovery). Treated as illustrative, not evidence.
