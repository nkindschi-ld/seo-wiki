# Search Engine Land — MOFU Keywords Guide (Edwards, 2025)

**Citation:** Katlyn Edwards, "MOFU Keywords," Search Engine Land (guide), last
updated November 27, 2025. https://searchengineland.com/guide/mofu-keywords

A **classic-SEO** guide on middle-of-funnel (evaluation-stage) keyword strategy. Ingested
as a source + light cross-links; it overlaps heavily with the wiki's existing funnel /
keyword-mapping / SaaS coverage and contains **essentially no AI/AEO/GEO content**.

## What it adds (the additive bits)

- **A vertical-agnostic five-type MOFU keyword taxonomy:** comparison ("X vs Y"),
  best-of ranked lists, feature-driven ("CRM with WhatsApp integration"),
  industry-specific ("accounting software for freelancers"), pain-solution ("how to
  reduce churn in SaaS"). Generalizes the SaaS-specific comparison/features/industries/
  alternatives taxonomy in [[gofishdigital-seo-for-saas]] / [[semrush-saas-seo]].
- **Measure MOFU on assisted conversions**, not direct: GA4 Path Exploration (MOFU page
  titles at Step +1 → downstream conversion paths) + multi-touch attribution
  (time-decay / position-based / data-driven), because MOFU converts over days-to-months.
- **Funnel-stage internal-linking pattern:** BOFU links → product/pricing, TOFU links →
  educational, lateral → related MOFU.
