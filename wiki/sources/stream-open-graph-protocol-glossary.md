# Open Graph Protocol: What Is It and How Does It Work? (Stream glossary)

**Citation:** Stream (getstream.io). "Open Graph Protocol - What is it and
how does it work?" Glossary page, undated, no author.
https://getstream.io/glossary/open-graph-protocol/

**Rigor note:** a vendor glossary entry (Stream sells chat/feed APIs). No
author, date, sources or data. It's the weakest of the four OG sources.
Cite it for the definition only.

## Key takeaways

- OG was developed by Facebook in **2010** to standardize link previews.
  Tags in `<head>` are read by platform crawlers to build preview cards.
- Required: `og:title`, `og:type`, `og:image`, `og:url`. Optional:
  `og:site_name`, `og:description`, `og:video`, `og:locale`.
- Specs as given: title 60–75 chars, description <200 chars, image
  "1200×630px or smaller." Canonical URL only in `og:url`. Test with the
  Facebook Sharing Debugger. Add Twitter/X Card tags alongside OG.
- Claims "improved social signals supporting search engine rankings"
  with no evidence. This conflicts with other sources (see below).
