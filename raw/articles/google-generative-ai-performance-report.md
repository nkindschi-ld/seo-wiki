# Generative AI Performance Report (Search) — Search Console Help

Source: https://support.google.com/webmasters/answer/16984139?hl=en
Retrieved: 2026-07-23

## Overview

This Google Search Console help page explains the generative AI
performance report, which tracks how websites perform within Google's
AI-powered search features.

## Key purposes

The report allows site owners to:
- Track organic impression changes from Search generative AI features
  over time
- Identify which pages receive the highest (or lowest) visibility in AI
  features
- Understand impression sources by device type and geographic location

## Access & availability

The feature is rolling out gradually to website owners. Sites may not
see the report if they lack sufficient impressions in AI features or
haven't been included in the rollout. Preliminary data is indicated by
dotted lines and may change within hours.

## Covered features

The report includes data from:
- "AI Overviews"
- "AI Mode"

The documentation notes that "experiments in Search Labs" are excluded
as they remain under active development.

## Configurable dimensions

Users can organize data by:
- **Pages** — Final URLs linked by AI features (using canonical URLs)
- **Countries** — Search origin location
- **Dates** — Daily, weekly, or monthly views (Pacific Time)
- **Devices** — Desktop, tablet, or mobile

## Data presentation

Information displays via chart (aggregated impressions, by property) and
tables (dimension-specific data, grouped by selected dimension),
sourced from web search types.

## Practical value

Helps content creators identify which pages generate the most AI-feature
impressions and optimize visibility across different geographic markets
and device types.
